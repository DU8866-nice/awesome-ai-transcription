# 贡献指南 · Contributing

欢迎推荐项目、纠正错误或补充说明。English version below.

## 怎么提交

- **推荐项目**：[提交 Issue](https://github.com/DU8866-nice/awesome-ai-transcription/issues/new/choose)，写上仓库地址、支持的系统和一句话说明。
- **直接改**：编辑 [`data/tools.yaml`](data/tools.yaml)，把条目加到合适的分类里，然后提 PR。README 由 `scripts/build_readme.py` 生成，请不要直接改 README。

每个条目需要：

```yaml
- repo: owner/name
  zh: "一句话中文说明：它做什么、适合什么场景。"
  en: "One-sentence English description."
  os: [win, mac]   # 可选：win、mac、linux、android、ios、web
  offline: true    # 可选：README 写明能完全本地运行时填
  byok: true       # 可选：核心功能需要自备 API Key 时填
  cn: true         # 可选：有中文界面或文档，或专为中文场景做时填
```

本地预览：

```bash
pip install pyyaml
GITHUB_TOKEN=你的token python scripts/update_stats.py   # 可选，刷新星标
python scripts/build_readme.py
```

## 收录标准

- GitHub 上的开源项目，和实时字幕、同声传译、会议纪要、语音输入或音视频转写直接相关。
- 能实际使用：有可安装的版本或清楚的使用说明。
- 说明要客观，写清楚是否需要 API Key、支持哪些系统。
- 一年以上没有更新会标 💤，已归档的标 📦，链接失效的会移除。

不收录：

- 标榜“隐身”的面试、考试作弊助手；
- 以偷录、窃听、侵犯隐私为卖点的工具；
- 刷星、仿冒或来源不明的安装包分发仓库。

## How to contribute

- **Suggest a project**: [open an issue](https://github.com/DU8866-nice/awesome-ai-transcription/issues/new/choose) with the repository URL, the systems it supports and one sentence about it.
- **Edit directly**: add an entry to [`data/tools.yaml`](data/tools.yaml) in the right category and open a PR. The README is generated by `scripts/build_readme.py`; please don't edit it by hand.

## What gets listed

- Open-source projects on GitHub for live captions, interpreting, meeting notes, dictation or transcribing recordings.
- Usable: an installable release or clear instructions.
- Plain descriptions that say whether an API key is needed and which systems are supported.
- Projects with no update for over a year are marked 💤, archived ones 📦, and dead links are removed.

Not listed: "stealth" interview or exam cheating assistants, tools pitched at secret recording or eavesdropping, and repositories with fake stars, impersonation or installers of unknown origin.
